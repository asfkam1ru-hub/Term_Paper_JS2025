Use Case: "Проведение тренировки слов"
Предусловия:

Пользователь находится на главной странице приложения (/)

В словаре уже есть хотя бы 5 слов (добавлены заранее или через DictionaryPage)

Основной поток:

Пользователь нажимает кнопку "Начать тренировку" на главной странице

Система переходит на страницу /training

Система загружает список слов для тренировки

На экране отображается первое слово и 3–4 варианта ответа

Пользователь выбирает вариант ответа

Система проверяет правильность и подсвечивает результат

Система обновляет прогресс и показывает следующее слово

Шаги 5–7 повторяются, пока не будут показаны все слова

После окончания списка слов система показывает итоговый экран:

количество правильных ответов

процент точности

рекомендации (например “потренируйте сложные слова”)

Пользователь может:

начать новую тренировку

перейти к словарю

перейти к статистике

Альтернативные потоки:
A1. Недостаточно слов для тренировки

Пользователь нажимает “Начать тренировку”

Система проверяет количество слов

Если слов меньше 3, система показывает сообщение:
“Недостаточно слов — добавьте минимум 3 слова в словарь”

Пользователю предлагается перейти на /dictionary

A2. Пользователь выбирает неправильный ответ

Пользователь нажимает неправильный вариант

Система подсвечивает его как неверный и показывает правильный

Статистика неправильных ответов увеличивается

Пользователь переходит к следующему слову

A3. Ошибка загрузки слов

Система не может загрузить слова (локальное хранилище повреждено)

Показывается сообщение об ошибке

Пользователю предлагается очистить словарь или попробовать снова
