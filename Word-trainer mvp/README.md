📘Тренажёр иностранных слов
Учебный проект, состоящий из двух независимых Node-проектов в одном репозитории:

frontend/ — SPA-тренажёр изучения иностранных слов (React + TypeScript + Vite)

ui-library/ — небольшая TypeScript-библиотека с собственными тестами, сборкой и линтингом

Оба проекта соответствуют требованиям:

Тип проекта — module, используются ES-модули (import/export)

TypeScript как основной язык

ESLint c правилами без ;, отступы — 2 пробела, запрет any

Jest для тестов и покрытия

Команды lint, lint:fix, test, test:coverage в обоих package.json

Покрытие тестами ≥ 90% хотя бы у одного компонента

Папки coverage/ и node_modules/ — в .gitignore

🧩 Описание функционала (Frontend)
Приложение представляет собой тренажёр для изучения слов по колодам:

📚 Колонки интерфейса
Колоды — слева

Список слов выбранной колоды (выдвижная панель)

Подробная информация о слове

Flash-карточки по текущей колоде

🔍 Детализация слов
При нажатии на слово открывается подробное окно:

слово

перевод

пример контекста

перевод примера

При повторном нажатии окно закрывается.

При выборе другой колоды — всё сворачивается.

🃏 Flash-карточки — два режима
1) Последовательный режим
Карточки идут по порядку

Кнопка Следующая карточка

При клике карточка переворачивается

2) Режим Anki
У карточек кнопки: Помню / Не помню

«Не помню» → карточка уходит в список сложных

После прохода всей колоды:

если есть сложные — показываются только они

если все «Помню» — цикл сбрасывается

🚀 Инструкция по запуску (с нуля)
1. Установка зависимостей
Каждый проект устанавливается отдельно.

Frontend
cd kamil-word-trainer/frontend
npm install


UI-library
cd ../ui-library
npm install


▶️ Запуск Frontend

cd kamil-word-trainer/frontend
npm run dev
Открыть в браузере:

http://localhost:5173/
